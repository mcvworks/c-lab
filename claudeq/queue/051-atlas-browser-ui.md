## Objective
Create a visual browser for captured cymatics patterns in the Library.

## Requirements
- New "Atlas" section in Library (or sub-section within Discoveries)
- Grid of captured patterns organized by plate shape (circle/square/hexagon)
- Each card shows: thumbnail visualization, frequency, waveform, node count
- Completion tracker per plate shape
- Tap to view full-size pattern with details
- Delete individual patterns

## Acceptance Criteria
- [ ] Atlas section visible in Library
- [ ] Patterns grouped by plate shape
- [ ] Cards show key info
- [ ] Shape completion counts displayed
- [ ] Tap opens detail view
- [ ] Delete works
