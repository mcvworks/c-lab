## Objective
Show a toast/banner when the user discovers a new frequency.

## Requirements
- Toast/banner slides in from top when a new frequency is discovered
- Shows frequency name, value (Hz), and category icon
- Auto-dismisses after 3 seconds
- Tappable to navigate to Library > Discoveries
- Subtle glow pulse animation (premium, not confetti)
- Works on any tab where discovery can happen

## Acceptance Criteria
- [x] Toast appears on new discovery
- [x] Shows name, frequency, category
- [x] Auto-dismisses after 3s
- [x] Tap navigates to Library
- [x] Animation is subtle and premium
